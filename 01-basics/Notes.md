## pwd 
Prints the current directory path

**Example:**
pwd
Output: /home/ubuntu

**When I use it:**
whenever I'm lost in the terminal and need to know ahere I am.


## ls
Prints the files present in the working directory

**Example:**
ls
Output: File1.sh Index.html newfile.txt

**When I use it:**
When i want to know what files are prensent in my directory
